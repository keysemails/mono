# /default-project skill

Set or update the default project for session start. Creates a `.PROJECT` file at mono root that the session-start hook uses to pre-select the project context.

## Usage
```
/default-project
/default-project @(project-name)
```

## Instructions

### 1. Detect Available Projects

Run the detection script to gather all project information:

```bash
.claude/scripts/detect-project.sh
```

### 2. Present Project Options

If no argument provided, present options using [[meta - numbered lists for instructions]] pattern:

```
Available projects:

1 - mono (meta repo)
  - 1.1 - Memory: mono/memory/
2 - [project-a]
  - 2.1 - Path: repo/project-a/
  - 2.2 - Memory: [local/external/none]
3 - [project-b]
  - 3.1 - Path: repo/project-b/
  - 3.2 - Memory: [local/external/none]
0 - Clear default (remove .PROJECT file)
```

If argument provided, resolve it to a project name.

### 3. Gather Memory Preference

For subprojects with multiple memory options, ask:

```
Memory preference for [project]:
1 - External memory (Recommended)
  - 1.1 - Location: [project].memory/
2 - Local memory
  - 2.1 - Location: repo/[project]/memory/
3 - Mono memory only
```

### 4. Write .PROJECT File

Create or update `.PROJECT` at mono root:

```yaml
# Default project for session start
# Generated by /default-project skill
# Delete this file to return to interactive project selection

project: [project-name]
path: [relative path from mono root]
memory_preference: [external|local|mono-only]
```

For mono itself:
```yaml
project: mono
path: .
memory_preference: local
```

### 5. Confirm

Report the update:

```
Default project set:
- Project: [name]
- Path: [path]
- Memory: [preference]

Session start will now auto-select this project. Run `/default-project` with option 0 to clear.
```

## Clearing the Default

If user selects option 0:
1. Delete the `.PROJECT` file if it exists
2. Confirm: "Default project cleared. Session start will prompt for project selection."

## Output

Creates/updates: `.PROJECT` at mono root
