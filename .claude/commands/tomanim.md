# /tomanim skill

Convert markdown files to manim-animated videos.

## Usage

```
/tomanim @(file)
```

## Instructions

This skill delegates to the tomanim subproject. Read and follow the full instructions at:

**[[repo/tomanim/.claude/commands/tomanim.md]]**

The tomanim implementation handles:
- Markdown analysis and content extraction
- Visualization planning
- Manim script generation
- Video rendering

Output goes to `repo/tomanim/output/yyyy-mm-dd-hhmm-<name>/`.

ARGUMENTS: $ARGUMENTS
